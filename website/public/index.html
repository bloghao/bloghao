五分钟，把博客搬到云上

需要一个免费的 Cloudflare 账号，完事。

推荐一键部署：授权 GitHub 后，Cloudflare 自动复制仓库、开通 D1 数据库与 R2 图床、构建上线并接管 push 自动部署——全程不碰命令行。

部署前想先试试？先去演示站转一圈 —— 预置全年仿真数据，账号 demo / demo1234，每 2 小时自动重置。

喜欢命令行？照下面四步来：

  1. 克隆并安装 
    git clone https://github.com/bloghao/bloghao.git
cd bloghao && npm install
npx wrangler login
  2. 创建资源（D1 数据库 + R2 图床） 
    npx wrangler d1 create xwblog-db
npx wrangler r2 bucket create xwblog-images
# 把返回的 database_id 填进 wrangler.jsonc
  3. 初始化数据库并部署 
    npx wrangler d1 execute DB --remote --file schema.sql
npm run deploy
  4. 创建管理员，开写！

    访问 https://bloghao.你的子域.workers.dev/admin/，首次进入即创建管理员账号，欢迎文章已就位。
