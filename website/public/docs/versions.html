v2.4 · 2026-10-11 —— 发布前全面审计，广场长出自愈路

开源第八天给代码库做了一次「体检」：五路并行审计（安全核心 / API 与会员 / 数据层 / 前端 / 渲染与基础设施）把防线最后一公里补齐——出网抓取全部收口统一 SSRF 防线（私网拒绝 + 重定向逐跳复查 + 响应体限长）、演示站出网端点全部短路、冷启动建表与备份恢复补上自愈路径（此前的坑：特定冷启动整站 500 窗口、恢复备份后关键词搜索静默失效）。回归测试 487 → 518，会话 token、净化器 style 白名单、出网重定向、上传魔数这些此前没有守卫的安全核心面，从此个个有测试盯着。

功能侧，广场长出微博补漏自愈路：微博此前只靠发布瞬间的推送上广场，推送失败即永久缺席——现在 hub 定时拉取站点公开微博对齐（推送优先、拉取只补漏不覆盖），管理端可手动触发；广场页信息流同步升级三段式布局（左身份位 / 中内容 / 右缩略图）。

v2.3 · 2026-10-11 —— 阅读体验全面升级，界面走向多语言

这一代把力气花在「读」上：读者侧补全了进度条、目录高亮、热力图、上下篇与楼层号一整套阅读动线；站长侧拿到外观变量与英文测试版两件「不动代码改站」的利器。

  • 英文测试版（English 0.1）：后台「设置 → 语言版本」一键把前台界面整体切成英文（文章与微博正文保持原文），页面顶部公示测试版横幅、测试期搜索引擎不收录；英文渲染一旦异常自动回退中文版并在后台红色提醒。站长自填的内容原样透传，中文版输出与历史版本字节级一致。
  • 主题外观变量（内测）：后台「皮肤 → 外观变量」直接调 7 个语义颜色（主色 / 正文 / 次要 / 背景 / 卡片 / 分隔线 / 链接）+ 正文字体（衬线 / 黑体 / 自定义栈）+ 正文字号（14-22px），不动代码即时生效、可一键恢复默认；颜色与字体栈全白名单校验，注入尝试整体拒绝。
  • 沉浸阅读工具条：文章页顶部主色阅读进度条（七主题各自着色），wechat 主题导航全站吸顶——下滚收起让位正文、上滑即回；桌面端目录卡随滚动高亮当前小节，文章页新增目录与文章信息侧栏。
  • 创作热力图：归档页新增 GitHub 风年历——过去一年每天的发帖密度一目了然，色阶跟随各主题主色，悬浮显示日期与当天篇数，窄屏默认滚到最新一周。
  • 上一篇 / 下一篇 + 标题锚点：文末导航补全阅读动线（缺一侧出占位保持两端对齐）；正文所有 h2/h3 获得稳定锚点，桌面端悬停标题点 ¶ 即复制带锚点的链接直达该节。
  • 评论楼层号与楼主徽标：评论区带 #N 楼层编号（楼中楼不占号），作者徽标在文章与微博语境显示「楼主」、留言板沿用「作者」。
  • 阅读小件一批：长文滚动过一屏后右下角「返回顶部」；代码块右上角一键复制；404 页「🎲 随机一篇」；归档页「今年已写 N 篇 · 约 X 万字」年度统计；后台回收站显示「N 天后自动彻底清除」倒计时。
  • 页脚站点名片：全站页脚升级为名片式——头像、站名与简介 +「共 N 篇 · 约 X 万字 · YYYY 年写起」站点足迹；统计由每晚备份任务刷新，不给页面渲染增加任何查询。
  • RSS 订阅更顺：顶部导航新增 RSS 订阅入口（图标随主题配色）；/feed、/rss、?feed=rss2 等惯用订阅路径全部自动指向规范地址 /rss.xml，按习惯猜路径也能订上。
  • 新站引导卡：一篇文章都没有的新站，首页出现「三步开张」卡——写第一篇 / 挑皮肤 / 补站名头像简介，每步直达后台，发布第一篇内容后自动消失。
  • 后台信息架构整改：设置页 11 个面板收进「站点 / 互动 / 进阶 / 数据」四页签（页内切换不丢未保存输入），侧栏按职能四组重排，「分类」并入文章页。
  • 新主题「小红书 rednote」：发现页瀑布流笔记卡 + 品牌红点缀，第七套主题。
  • 安全加固：全链路安全审查——服务端抓取外部资源统一 SSRF 防线（重定向逐跳复查、限长限时）、HTML 属性双重转义、演示站禁外发、自托管形态加固。

v2.2 · 2026-10-10 —— 会员体系与创作装备大版本

迄今最大的一次功能更新：互动与创收（会员 / 积分 / 排行榜）与内容保护（访问密码）落地，搜索与编辑器两大核心体验升级，「广场」把所有博客号连成一片。

  • 会员体系与积分（默认关闭，后台一键开启）：访客可注册登录（独立于站长账号），评论免填昵称、带档位徽标；发表留言评论 +2 分（先审后展模式下过审才计、同一条只计一次、单日上限）、每日登录 +1 分；/rank 积分排行榜，自己的名次高亮。
  • 会员专属文章：编辑器「谁能看」四档（公开 / 仅登录会员 / 咖啡会员 / 顶级会员）——非目标读者只拿到服务端截断的试读段与升级遮挡卡，浏览器拿不到全文；RSS 全文、公开接口、卡片摘要同步收敛为摘要口径。
  • 文章访问密码：单篇加密访问（服务端 PBKDF2 单向哈希，不回显），输对后 30 天免重复输入；锁定期间正文 / 自动摘要 / RSS 全文一概不外泄，关键词搜索不命中加密文章。可与会员档位叠加：密码墙优先，解锁后再按档位判定。
  • FTS5 全文搜索：搜索从 LIKE 全表扫描升级为 SQLite FTS5 全文索引（trigram 分词适配中文），按相关度排序，站内微博正文一并纳入；不足 3 个字的短词自动走原匹配逻辑。
  • 编辑器写作五件套：表格（行列操作条 + Markdown 管道语法往返不丢）、查找替换（⌘/Ctrl + F）、本地备份兜底（未保存输入每 2 秒留档，断网崩溃后可恢复）、点击图片即改（alt 描述与显示宽度）、专注模式（一键只留写作纸面）。
  • 链接卡片：「插入链接」升级三页签——网址卡片自动抓目标页标题 / 摘要 / 配图，站内文章卡片带封面与摘要；插图弹窗接媒体库，已有图片直接复用。
  • 广场：官网新增内容聚合流 bloghao.com/plaza——所有开通同步的博客号，其公开文章与微博按「权重 + 新文推荐 + 随机」混排成一条河；加密文与会员专属文不上广场，不想同步关掉插件即可。
  • 外链跳转提醒：文章 / 页面 / 微博里指向第三方网站的链接，访客点击先经过「即将离开本站」确认页（主流大站白名单直跳）；微博正文链接自动超链化（不吞中文与句尾标点）。
  • 微信表情：编辑器与微博发布器接入整套 117 个默认表情文本码（[微笑] ~ [转圈]），正文、微博、评论区渲染成行内小图；存库保持纯文本，RSS / 导出 / 搜索不受影响。
  • QQ 评论头像：会员可绑定 QQ 号（不公开展示），文章 / 留言板 / 微博评论区与排行榜显示头像；游客评论也可选填亮头像。头像服务端抓取后转存站内图床，QQ 号本体不出现在任何页面。
  • 上传图片自动剥离 EXIF / GPS：所有进入图床的图片落库前剥掉拍摄坐标与设备信息——纯字节摘除、零画质损失；手机照片不再带定位上网。
  • 新主题「比特币 bitcoin」：比特币橙 × 暖白纸面的品牌素材库风（描边分层、衬线大标题、等宽眉题），第六套主题。
  • 自托管与同步增强：Docker 多租户网页控制面（开站 / 停用 / 重置密码免重启）+ 一条命令开新站的开台脚本 + 1GB 小机部署清单；服务端插件新增「微博同步 Buffer」，发微博免费自动同步到 X 等平台。
  • 细节与修复：中文标题自动 slug 改为「发布日期 + 随机位」更可读；图片压缩全端统一并收紧（WebP 视觉无损）；演示站迁至正式域名 demo.bloghao.com；修复 iOS 手机「选了图发布只剩文字」的静默失败、后台会员接口越权等一批问题。

v2.1 · 2026-10-06 —— Docker 自托管

同一套业务代码零改动跑进普通 Node 容器：不想把博客跑在 Cloudflare 上、手头有 VPS 的用户多了一条路（Cloudflare 版部署方式不变）。

  • Docker 自托管：文章存内置 SQLite（WAL），图片存本地磁盘目录或 Cloudflare R2 桶（S3 兼容接口直连、零依赖实现 SigV4）；单进程按域名托管多个完全独立的博客站（库与上传物物理隔离），定时发布与北京时间 00:30 备份、回收站清理随容器运行；已在真实服务器全链路排练通过。
  • 回收站首批加固：彻底删除的级联清理由裸删改守卫式子查询（不再误删存活文章的评论）；恢复端点补软删守卫；过期定时文恢复自动转草稿并清掉定时（防「恢复即撞发」）。

v2.0 · 2026-10-06 —— 正式版基线

首个正式发布版本：确立「开发 / 发布双仓」流程，官网 bloghao.com（朱砂红新版）与官方演示站（每 2 小时自动重置的完整体验环境）同日上线。2.0 在「写文章」的基础上，整合孵化期沉淀的完整能力面：

  • 短内容「微博 / 随手记」：图文时间线、话题归类、置顶、点赞与楼中楼评论，登录后前台可直接发布
  • 公众号风写作后台：富文本 + Markdown 双模式、行首快捷排版、定时发布、粘贴图片自动压缩上云
  • 评论互动：文章与微博楼中楼、作者回复徽标、先审后展、站点级开关
  • 数据主权：一键导出（Markdown + 图片打包 / WordPress WXR），内容随时带走
  • 独立页面系统与导航自定义、JSON-LD 结构化数据、站点模式（博客 / 微博自由组合与排序）
  • 扩展体系：编辑器插件、服务端插件钩子（TG 频道同步 / 评论 Webhook / 页脚代码）、皮肤与插件市场
  • 运维省心：媒体库体检（未引用 / 重复文件扫描清理）、回收站（删除 30 天可找回）、一键灰度 / 闭站、定时备份与告警
  • 五套主题全部适配移动端；官方演示站每 2 小时自动重置体验

v1.0 · 2026-10-05 —— 主题与市场体系成型，功能全景补完

从「能写」到「好用」的一天：博客该有的一整圈能力补完，主题与扩展有了自己的家。

  • 第五套主题「手账 journal」：奶油纸面手账风（和纸胶带、拍立得、贴纸标签、日历牌日期、便签留言墙），跟随系统自动暗色。
  • 皮肤与插件市场：后台新增「皮肤」「插件」独立页——主题卡片点击即启用、插件一键启停，内置市场目录（本地已装角标、远程目录预留扩展点）。
  • 后台信息架构升级：侧栏改为配置数组驱动、按「数据 / 内容 / 系统」分组并高亮「写作」入口；移动端改固定五项底栏 +「更多」抽屉。
  • 独立页面系统：自定义页面（后台管理、拖动排序、注入导航）+ 导航自定义；「关于我」迁入页面系统，短链不变。
  • 数据主权落地：一键导出 Markdown + 图片包（流式 zip，图片不过内存）与 WordPress WXR，后台一键下载。
  • 发现与分享：文章页 JSON-LD 结构化数据（利于搜索引擎理解）；社交分享卡图三级兜底（文章专属卡图 > 站点默认卡图 > 内置兜底图）绝不缺位。
  • 一键部署与访客统计：README 与官网接入 Deploy to Cloudflare 按钮（点一下部署自己的博客号）；前台轻量打点，后台新增「统计」页。
  • 站点状态开关：一键灰度（全站变灰）与一键闭站（503 + 保收录）。

v0.4 · 2026-10-04 —— 生态与运维

博客开始连接外部世界，也让站长睡得着觉。

  • 公众号采集插件：编辑器一键采集公众号图文——抓正文、配图 / 封面自动转存图床、保留原发布时间生成草稿。
  • Telegram 机器人发微博：TG 里发文字 / 图片 / 相册即发微博（图片转存图床、Chat ID 白名单、相册自动合并）；同时开放 Token 鉴权的发布 API，写自己的客户端成为可能。
  • 独立页面三件套：「关于我」升为一级导航页，新增文章归档 /archives（按年分组、利于收录）与留言板 /guestbook（复用评论体系，楼中楼 / 先审后展 / 蜜罐限流全兼容）。
  • 首页时光机：「历史上的今天」把往年今天的文章与微博翻出来放到首页。
  • 更省心的运维：RSS 全文输出（可切回摘要）、新留言 Telegram 推送、每晚北京时间 00:30 自动备份到 R2（滚动留 30 份、失败提醒、后台可立即备份）、定时发布。
  • 质量防线建立：回归测试（首轮 30 个用例、CI 每次推送强制执行）与本地冒烟脚本上线——修过的 bug 从此有护栏；旧站数据迁移工具打通（Memos 285 条微博与 108 个附件成功迁入）。

v0.3 · 2026-10-04 —— 长出社交

博客不再只是「发文章」：短内容、评论与友链让站点有了人气。

  • 微博 / 随手记：图文时间线 + 后台 / 前台双发布器（粘贴、拖拽传图）、置顶、#话题# 归类、首页微博入口卡；管理员登录后微博页顶部直接发。
  • 评论互动：文章 / 微博评论楼中楼、作者回复徽标、点赞、卡片内折叠评论；先审后展与蜜罐限流照常生效。
  • 友情链接：/links 页 + 访客申请收录（限频 / 蜜罐 / 去重）+ 后台审核管理；站点图标自动获取并入图床。
  • 发现内容更容易：站内搜索 + 排序筛选（最新 / 最多阅读 / 最多点赞 / 最多留言 / 随机）、随机阅读、全站顶部导航（分类话题折叠菜单）。

v0.2 · 2026-10-03 —— 定名「博客号 BlogHao」

开源当天下午，项目有了自己的名字与性格。

  • 品牌定名：墨博 MoBlog → 博客号 BlogHao——「微信有公众号，你有博客号」。
  • 视觉定调：后台与前台点缀色统一朱砂红、暖纸底色；首页改居中刊头 + 日期流编辑部式排版；文章页排版层级强化（H2 朱砂竖条、H3 圆点、暖底引用、深色代码块、斑马表格）。

v0.1 · 2026-10-03 —— 项目诞生

「墨博 MoBlog」首个可用版本开源：一个完全跑在 Cloudflare 免费套餐上的轻写作博客系统。

  • Cloudflare 全家桶：Workers（hono 路由）+ D1（SQLite）+ R2（图片存储）；后端约 10 个 TypeScript 文件、无前端框架、无构建链，改完即生效；SSR 直出 + 主题 CSS 内联，免费额度即可长期运行。
  • 公众号风写作后台：标题 / 正文 / 封面 / 标签一屏完成，截图 ⌘V 粘贴即上传图床；富文本与 Markdown 双模式互转、自动保存草稿、内置微信排版规范体检。
  • 四套主题：微信公众号（默认，支持 Dark Mode）、纸墨、极简、夜航——主题即代码模块，开放注册。
  • 安全基线：PBKDF2 口令哈希、HttpOnly 会话 Cookie、同源校验防 CSRF、HTML 白名单净化防 XSS、评论蜜罐 + 限流、CSP 安全响应头。
  • 博客标配自带：RSS / sitemap / robots.txt / OG 分享标签；开源当天附上完整 README、使用手册、部署教程与官网落地页。
