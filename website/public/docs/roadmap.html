    开发方向（ROADMAP）

    原则：少而准。只登记「确定要做」「待拍板」「已拍板不做」三种事，其余随缘不立项；一件事做完就归档成一行大事记，不复述细节（细节在 版本更新说明 与 更新日志）。历史编号（A / B / C）保留一份对照表收档，新文档不再使用这套编号。

    一 · 接下来做什么

    排期内（按价值排序，下一批就从这里取）

    方向 一句话说明 备注
    搬家导入工具 从 WordPress / emlog / Typecho 一键导入文章与图片——换博客用户的主要入口，对获客的价值大于一切 SEO 微优化 调研已入档：WXR 解析、正文转 Markdown、图片转存的积木全有，工程量在 wp: 元数据映射；scripts/ 留有 emlog 迁移脚本可复活
    通知渠道抽象 TG 之外加飞书 / 企业微信 / Bark / Server酱——国内用户装 TG 本身就是门槛；新留言 / 定时发布 / 备份告警复用同一渠道配置 优先插件形态（出站 Webhook 已能接 n8n / 飞书自建流）
    IndexNow 即时推送 Bing / Yandex 系秒级收录；插件形态，key 文件托管需内核几行 提案见 docs/archive/PROPOSAL-B21-INDEXNOW.md
    旧 slug 301 重定向 文章改 slug 后旧链接 404、搜索权重断链；两条实现路（old_slugs 列 / 独立 redirects 表）待拍板 个人小站改 slug 频率低，但断链伤害不可逆
    管理员安全包 TOTP 两步验证 + 登录失败告警 + 活跃会话管理——安全是招牌卖点，招牌要焊牢
    备份异地化 每晚备份额外推一份到 GitHub 私库或另一账号（D1 与备份 R2 同账号，被盗一锅端） 插件形态路子已就绪：onBackupCompleted 钩子已上线，不必进内核

    待站长拍板（先拍板再立项）

    • 会员支付闭环：收款方式（卡密 / 爱发电类轻方案优先，避免重对账），打通后会员档位可自助购买，再往后是升级补差价与兑换码。
    • 广场作者认证：站点所有权验证后发认证徽标（蓝V式），sites.verified 徽标位已预留；认证分级与是否收费待拍板。
    • 内容揭示卡：正文内一段内容按「点击展开 / 会员档位可见」揭示——安全边界必须同样做到服务端截断，先研究再动手。

    随缘小件（有富余再做，不排期）

    • 后台 PWA 可安装（添加到主屏幕，贴合手机操作站长的「像 App」方向）
    • 图片表情回应（emoji reactions，微信表情文本码可复用）
    • 创作增强：代码块语法高亮 / KaTeX 公式 / mermaid 图表 / 文章目录（倾向手写小型 tokenizer 或插件形态，不引全家桶）
    • 新站演示内容包（一键填充示例内容，方便部署者开站）
    • 404 自定义页打磨与无障碍（a11y）小改进
    • 主题 / 插件市场分发仓库（独立仓库托管皮肤包与插件包）
    • 广场 2.0 后续（本地关注 / 周刊精选 / 话题与搜索 / 信任治理）——按广场活跃度里程碑触发
    • 官网博客号目录深化（每站截图 + SEO 落地页，对标 WordPress showcase）
    • 读者端手动夜间 / 护眼开关

    四 · 不做清单（拍板记录，防止反复重提）

    • 邮件相关（发信 / 订阅 / 邮件通知 / 邮箱找回密码）：第三方发信服务与 DNS 配置门槛高、免费档说砍就砍（MailChannels 砍 Workers 免费集成是先例）。会员密码找回已按「本站不提供密码找回」口径落地，不再视作欠账。
    • AMP / hreflang / Google ping：AMP 已边缘化；hreflang 与英文版单语回退形态不匹配；Google ping 已被官方弃用（sitemap 是唯一通道，Bing 系补位靠 IndexNow）。
    • AI 代理生态协议接入（API Catalog / OAuth Discovery / A2A / WebMCP / x402 等一整批）：面向电商与 SaaS 的代理发现 / 授权 / 支付协议，博客号没有商品也没有 API 产品，逐项接入纯属自加维护负担。同页的 Content Signals 已由 AI 抓取策略落地，属另一回事。
    • Markdown 内容协商（按 Accept: text/markdown 返回 Markdown，Cloudflare Pro 套餐能力）：/post/:slug.md 静态镜像已达到同一目的，再做协商属重复建设。
    • 完整主题与服务端插件的运行时安装：Workers 不能加载 bundle 外代码，重部署违背「部署即生效」体验——布局差异走官方主题演进 + 皮肤包，服务端插件走官方注册表 PR 模式。
