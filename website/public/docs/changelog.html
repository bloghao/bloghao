    更新日志

    面向「博客号 BlogHao」部署用户的版本说明，每次官方发布（bloghao/bloghao 打 tag）时回填。格式遵循 Keep a Changelog，版本号语义见 docs/RELEASING.md「版本号」一节。

    升级方式：同步本仓库最新代码后重新部署即可，D1 结构自动增量迁移；个别需要手动动作的条目以「⚠️ 升级注意」标出。开发线的完整迭代细节见各仓库 git log——这里是给部署用户的要点。

    Unreleased

    （尚未发布的内容，日常随手记入，发布时整段移入新版本小节。）

    2.5.1 - 2026-10-12

    新增

    • 文档中心站内搜索：官网文档中心全页面顶部新增搜索框，按标题与正文关键词即时过滤，结果直达具体小节锚点；搜索索引独立文件按需加载，不拖慢首屏。同时修掉「文档页丢样式」——资源引用一律改根绝对路径，/docs（无斜杠）地址访问不再解析错资源；首页补文档中心入口

    修复

    • 分享卡片单图完整展示：微博只有一张配图时，卡片按图片真实比例完整绘制（与前台 .wb-imgs-1 同口径：不裁切、不放大，高度上限 420px，过长的图自动缩成完整缩略图，比例变窄时水平居中）；旧版写死 4:3 格子居中裁切，方形图上下共被裁掉约四分之一，图内文字常被切掉。多图九宫格与图加载失败的占位格维持原样

    2.5.0 - 2026-10-12

    本版本把「安全」升级为常态化机制：发布次日即完成第二轮全量审计（七类攻击面并行猎捕 + 独立复核，27 项发现 21 项修复，报告见 docs/），并顺手补上两块能力版图——AI 助手接入（MCP）与注册人机验证（Turnstile）；后台概览新增「系统」状态卡与版本号展示，运维状态从此一眼可见。

    新增

    • MCP 服务器（B10）：POST /mcp Streamable HTTP 无状态模式（JSON-RPC 2.0 手写零依赖，不开 SSE），AI 助手（Claude / Cursor 等）凭一枚令牌即可发文 / 发微博 / 查文章 / 查评论——鉴权复用开放 API 同一枚令牌（空 = 接口关闭），演示站与一键闭站自动关闭；业务校验失败回工具错误不透内部堆栈。用法见 GUIDE §8.3、协议契约见 docs/API.md
    • 注册人机验证（Turnstile）：后台「设置 → 会员」成对填入 Cloudflare Turnstile 的 Site Key / Secret Key 即启用——注册需先通过人机验证，批量小号刷积分的路子基本断掉；两键成对校验（只填一个整体拒绝），Secret 全链路打码，默认关闭、不开行为与从前完全一致。站点verify 校验 fail-closed：验证服务不可用时宁可暂挡注册，不留无验证窗口
    • 后台系统状态卡（B12）：概览页新增「系统」面板——微博 / 评论 / 会员体量、最近备份时间与体积、当前系统版本号，未开启备份有明确提示；/admin/stats 同步扩展出参
    • JSON Feed（C12）：/feed.json 输出 JSON Feed 1.1，与 RSS 共用同一份防泄漏口径（密码文只出作者自填摘要、会员锁文只出试读段、rssFullText 开关同效）；日期走北京时间口径
    • 评论区表情选择器：文章 / 留言板 / 微博评论三处输入框旁新增「😊 表情」入口，微信文本码表情一键插入，与编辑器同一套码表
    • 后台版本号展示：概览「系统」卡显示当前系统版本号（src/version.ts 镜像 package.json，守卫测试防漂移），升级核对不用再猜
    • 自托管控制面站点投稿：官网「他们也在写博客号」目录表单的投稿接收端点与投稿卡进控制面板（Origin 白名单 + 同 IP 每小时 5 条限流 + 同 URL 去重，落盘待人工上架）
    • 官网新增两页：2026-10 全量安全审计报告大众版（/docs/security-audit.html，普通用户也能看懂）与 Cloudflare 基础使用教程

    变更

    • wechat 主题导航与页脚重排：顶栏去掉「微博」独立入口（首页微博流头部自带「全部 →」，纯微博模式「首页」即微博），「留言板」「友情链接」进顶栏（挂在「关于我」后）；页脚不再重复微博/留言板/友情链接/关于我，只留 排行榜/随机/RSS/管理 等次级入口；移动端顶栏单行横滑断点从 480px 抬到 560px（多两项后一行装得下了）

    安全

    • 第二轮全量安全审计（2026-10-12），27 项发现 21 项修复，全部带回归测试。要点：
      • 积分日上限并发竞态：记账预查与写入不在同一事务，并发可刷穿「每日 20 分」刷排行榜——改为 batch 内条件写（条件 UPDATE + 超额条件 DELETE 谓词互斥），新增竞态回归用例
      • 公开写端点入站体积预检：非 GET 请求先看 Content-Length（常规 2MB / 上传与外部微博 multipart 30MB），超限 413——此前 ~99MB JSON 可整读进内存打爆 isolate
      • 密码文摘要泄漏：发布后补设访问密码时残留的自动摘要继续经 RSS / meta / 列表公开——现在设锁即与旧正文摘要比对清空，存量泄漏行下次保存自愈
      • 广场锁文生命周期闭环：RSS 加 <bloghao:locked> 机器可读标志、hub 拉取跳过锁文；加锁 / 升档 / 转草稿 / 删除即时广播 deleted 下架（firePlazaRetract）——「加密文不上广场」契约不再被订阅路绕过
      • 出网与代理加固：书影音封面代理改走统一 SSRF 防线（重定向逐跳白名单复查 + 流式限长，新增 opts.hostOk 钩子）；自配 Webhook / 广场端点落配置即过公网校验
      • 滥用面收口：会员评论限流叠加 IP 桶、统计打点限流收紧至 1/4、封禁会员过审不计分、关闭会员体系后存量会话按游客、恢复微博不再挤占置顶名额、TG webhook 按消息 ID 短窗幂等（超时重投不再重复发博）、演示站敏感面（备份 / 导出 / 粘贴转存 / 友链抓图）全部短路、commentWebhookUrl 进敏感键全链路打码
      • 加固位：/go 中间页补 frame-ancestors 'none'、编辑器预览补 noopener、外观查表与导出包条目名防原型链 / 路径注入、卡片链接生成时协议白名单
    • 回归测试 518 → 553，冒烟 189 项同步全绿；完整报告与逐条终态见 docs/SECURITY-AUDIT-REPORT-2026-10-12.md

    修复

    • wechat 移动端两处：真 390px 下评论头的作者/会员徽标与回复按钮被挤到框内拆字换行（「作者」拆成两行）——评论头放开 flex 换行、整字不拆；顶栏转横向滚动后「分类话题」下拉被滚动容器剪掉——菜单打开时放开导航裁剪并转导航锚定定位（site.js 切 snav-open，:has 兜底无 JS）
    • 英文测试版随 v2.4.0 代码补齐：feed 频道标题走词典、分享卡与配图删除按钮文案收尾
    • 自托管（docker-poc）：控制面镜像构建补齐 scheme.ts（新增兄弟模块未进 COPY 清单导致构建必炸）；广场 hub 的 Node 运行器源码入库（此前文档引用而源码漏提交）

    2.4.0 - 2026-10-11

    本版本是一次发布前全面安全审计的加固批次（五路并行审计：安全核心 / API 与会员 / 数据层 / 前端 / 渲染与基础设施），加上广场微博补漏自愈——微博上广场从此不怕推送失败，广场页信息流升级三段式布局。

    新增

    • 广场微博补漏自愈：微博此前只靠「发布瞬间推送」上广场，推送失败即永久缺席且没有自愈路——新增公开微博接口（GET /api/public/weibo，只读、仅已发布内容、无敏感字段），广场 hub 定时拉取对齐（推送优先、拉取只补漏不覆盖，超 30 天的旧内容不补）；hub 管理端新增「手动触发补漏」。协议见 docs/PLAZA.md「微博补漏」
    • 广场卡三段式信息流：广场页卡片升级为「左身份位 / 中内容 / 右内容缩略图」三段式布局，长卡短卡节奏更清晰

    安全

    • 出网统一入口收口：公众号采集抓取与友链图标抓取改走统一 SSRF 防线（私网拒绝 + 重定向逐跳复查 + 响应体流式限长）——此前重定向落点不复查、响应体不设上限
    • 演示站出网短路补齐：链接卡抓取、书影音搜索与封面代理三个端点此前在演示站可达（演示凭据公示），现一律 404，与「订阅与备份」外呼同口径
    • 冷启动与恢复自愈：独立页面建表语句补齐软删列（特定冷启动路径曾造成整站 500 窗口，并新增「建表必须自带全部补列」的不变量测试）；恢复备份后全文索引自动重建（此前记账位随备份回灌，恢复后关键词搜索会静默失效）
    • 杂项加固：链接卡抓取对畸形实体解码的 500 防护；书影音中转响应体流式限长；外部发布落库改「魔数优先」（声明 Content-Type 不可信）；会员锁文的社交卡图只出封面（OG 标记可能位于试读段之后）；采集草稿响应统一过口令剥离出口
    • 回归测试 487 → 518：会话 token 全模块（哈希落库 / 查询比对 / 限流）、style 白名单净化、出网重定向逐跳复查、上传魔数与原型链穿透、Markdown 协议拒绝列表、schema 同步不变量——安全核心里此前没有守卫的面全部补齐

    修复

    • 广场微博卡在「摘要与标题同文截断」时不再重复渲染（兼容截断省略号）；广场 hub 管理端手动拉取的参数修正（此前触发即 500）
    • 备份文件名与上传年月目录统一按北京时间取日期（此前走 UTC，北京每月 1 日 0-8 点会归错档）；文章页 canonical / og:url / JSON-LD 的中文 slug 百分号编码，与 RSS / sitemap 同口径
    • 后台友链 / 页面排序请求期间防连击（此前连点会挪两格）；公众号采集插件补中文输入法回车判定

    2.3.0 - 2026-10-11

    本版本带来 英文测试版（后台一键把前台整体切英文，异常自动回退中文）、主题外观变量（颜色 / 正文字体 / 字号不动代码即可调，内测）与一整批阅读体验升级——阅读进度条与吸顶导航、目录滚动高亮、创作热力图、上一篇 / 下一篇与标题锚点、返回顶部与代码块一键复制、评论楼层号与楼主徽标；页脚升级为站点名片、顶部导航新增 RSS 订阅入口（常用订阅路径全兼容），新站有「三步开张」引导卡，后台设置页重组为四页签、侧栏按职能重排。

    新增

    • 英文测试版（内部代号 English 0.1）：后台「设置 → 语言版本」可把前台界面整体切到英文（文章与微博正文保持原文），页面顶部公示测试版横幅、测试期搜索引擎不收录（noindex）；英文版渲染出现异常时自动回退中文版并在后台顶部红色提醒（含错误摘要与时间），重新开启即重置。机制与词典集中在 src/i18n.ts（站长自填内容原样透传，中文版输出与历史版本完全一致）；前台 JS 文案随 <html data-edition="en"> 切换
    • 页脚站点名片：全站页脚升级为名片式——左侧头像、站名与简介，右侧「共 N 篇 · 约 X 万字 · YYYY 年写起」站点足迹；统计由每晚备份任务刷新、冷启动自动播种，不给页面渲染增加任何查询
    • 导航 RSS 图标：所有主题的顶部导航末尾新增 RSS 订阅入口（图标随主题配色），博客圈的老朋友一眼就能找到订阅地址；wechat 主题移动端导航同步改单行横滑——会员开启时药丸不再被挤成孤儿行，「分类话题」下拉菜单转 fixed 定位逃出滚动容器裁剪
    • RSS 订阅别名：常用订阅路径盲猜兜底——/feed、/rss、/atom.xml、/index.xml、/feeds/posts/default 等惯用地址与 WordPress 风格的 ?feed=rss2 全部指向规范订阅地址 /rss.xml（同内容同缓存，阅读器按内容识别格式），访客或 AI 助手按习惯猜路径也能订上；前端展示、rel=alternate 与 sitemap 只出规范地址，不产生重复入口，闭站时别名同样拦截
    • 新站引导卡：一篇文章和一条微博都没有的新站，首页出现「三步开张」卡——写第一篇文章 / 挑一套皮肤 / 补上站名头像简介，每步直达后台对应页；发布第一篇内容后自动消失
    • 阅读小件三则：归档页往下滚时当前年份钉在页首（长列表有了坐标系）；点赞成功时爱心心跳一下（取消不弹）；外链确认页标题带上站名（「即将离开『你的站名』」），跳转前的最后一眼也是品牌
    • 阅读工具条 + 评论楼层：文章页顶部新增主色阅读进度条（七主题各自着色），wechat 主题导航全站吸顶——下滚收起让位正文、上滑即回，收起后左上角浮现当前章节胶囊接力报方位；wechat 桌面端目录卡随滚动高亮当前小节，滚动到哪跟到哪；文章与微博评论区带楼层号（#N 从 1 起编，楼中楼不占号，孤儿回复按顶层层级占号），作者徽标在文章与微博语境叫「楼主」、留言板沿用「作者」（双端渲染同构，镜像测试守着）。顺手新增 site.js 全文件语法守卫测试——一处解析错误即全站交互瘫痪，切片镜像测试拦不住顶层语法错误（本次实抓一例三元缺 else）
    • 创作热力图：归档页头部新增 GitHub 风年历——过去一年每天的发帖密度一目了然（列 = 周、行 = 星期，色阶 = 当前主题主色的透明度四档，空格 = 主题分隔线色，七主题各自长出自己的颜色），悬浮任意格子显示日期与当天篇数，底部一行「过去一年写了 N 篇」与少→多图例；窄屏打开默认滚到最右——最新的周直接怼在眼前，往左滑回看更早；色阶整体加深（0.30/0.55/0.78/满档），近况一目了然。数据按北京时间日聚合，未配置/无数据时不渲染
    • 上一篇/下一篇 + 标题锚点：文章页尾新增「上一篇 / 下一篇」导航（上一篇 = 更早一篇、下一篇 = 更新一篇，缺一侧出占位空位保持两端对齐，草稿预览不出；结构七主题共享、配色各主题自调）；正文里所有 h2/h3 标题获得稳定锚点（wechat 主题桌面端目录卡与锚点同源），桌面端悬停标题浮现 ¶ 按钮、点击复制带锚点的文章链接直达该节（触屏设备不显示防误触）。标题锚点由渲染层在净化之后统一注入，不影响正文净化防线
