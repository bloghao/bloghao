    更新日志

    面向「博客号 BlogHao」部署用户的版本说明，每次官方发布（bloghao/bloghao 打 tag）时回填。格式遵循 Keep a Changelog，版本号语义见 docs/RELEASING.md「版本号」一节。

    升级方式：同步本仓库最新代码后重新部署即可，D1 结构自动增量迁移；个别需要手动动作的条目以「⚠️ 升级注意」标出。开发线的完整迭代细节见各仓库 git log——这里是给部署用户的要点。

    2.6.0 - 2026-10-17

    新增

    • 管理员在前台直接删评论（2026-10-14）：文章评论区 / 留言板 / 微博评论区每条留言旁边都有「删除」键（登录管理员可见，访客 HTML 里不存在；与「回复」并排），点一下二次确认后连这条下面的回复一起删掉（评论没有回收站，不可恢复）——顺手把评论计数就地更新，删完当页立即消失，不用再回后台。写操作复用后台同一个端点（会话鉴权）

    • 微博视频（B19）：微博（随手记）现在能带 1 个视频（mp4 / webm，≤25MB）——前台发布器、前台卡片编辑、后台「微博」页三处都有「视频」按钮，点选 / 粘贴 / 拖拽都行，上传带实时百分比；发布端自动抽视频第一帧当封面帧（抓不到就退化成无封面卡，播放不受影响），卡片按原始宽高占位、竖屏自动居中限高，无封面时叠 ▶ 角标（开播即收）。媒体区顺序为 正文 → 视频 → 配图；分享卡用封面帧作图，广场与开放接口取封面帧当缩略图（视频文件不出站，也不进 RSS）。API 契约见 docs/API.md（video 字段缺键即保留，旧调用点不会把视频清掉）

    • 站长 SEO 自定义（B20）：后台「设置 → 站点 → SEO 与统计」新增三项——站点验证标签（一行一个 <meta>，支持 Google / Bing / 百度 / 搜狗 / 360 / Yandex 等验证字段）、统计脚本（provider 给的 <script src="…"> 片段或脚本地址，仅 https；Umami / Plausible / CF Web Analytics / 51la 这类「地址 + data-* 配置」的都能用，需要内联配置代码的 GA4 / GTM 不支持）、robots.txt 追加段（额外 Sitemap、屏蔽目录等，附在内置规则之后）。服务端只做「解析 → 结构化重放」，不开裸 HTML 注入口；统计脚本域自动同步进 CSP

    • 分类描述 + 面包屑结构化数据（B23）：分类可填一行描述（后台「文章 → 分类标签 → 编辑」），显示在分类归档页页头并作为该页的搜索引擎摘要；文章页与分类页输出 BreadcrumbList 结构化数据（与既有 BlogPosting 并列），搜索结果里能出路径层级

    • 链接预取 Speculation Rules（B24）：前台自动声明同源链接预渲染（conservative 档——鼠标按下链接才触发，排除后台 / 开放 API / 外链中间页 / 订阅端点），点进去几乎瞬开；Chrome / Safari 新版生效、老浏览器静默忽略。配套保证统计诚实：预取与预渲染请求不计文章阅读量，访客打点在预渲染期间不报、页面被真正打开时补报

    • 皮肤包与自定义 CSS（B8 拍板落地）：后台「皮肤 → 皮肤市场」新增皮肤包——一份完整配色预设（含圆角档位），点「应用」即刻换装、随时可换回，官方首批四款（苔原 / 蜜柑 / 方直 / 墨夜，其中墨夜可给浅色主题一键夜色）；也能把皮肤包 JSON 粘贴导入。配套自定义 CSS：追加在主题样式后全站生效，服务端「样式安检门」净化（@import 与脚本类内容拒绝、url() 只收 https 与站内地址、< 全剥防标签逃逸），安全边界不靠自觉

    • 外观变量 v2：圆角旋钮 + 实时预览（B9 转正）：外观面板新增「圆角」（0-24px，0 = 直角风格，主题默认留空跟随），七套主题的卡片 / 面板 / 图片圆角统一收编为可调变量（药丸按钮与圆头像保持原样）；改动即时反映在面板里的预览卡片上（颜色 / 字体 / 字号 / 圆角所见即所得），不用再开新窗口到处点

    • 服务端插件：事件槽扩面 + 配置通道 + 通用出站 Webhook：钩子从四个扩到八个——新增「编辑已发布文章」「文章 / 微博移入回收站」「备份完成」三个通知点（异地备份从此可以用插件做，不必改内核）；插件有了统一配置通道——插件在后台「插件」页出现「配置」按钮，填表即用，不用再等版本更新加设置项；新官方插件「通用出站 Webhook」：文章发布 / 更新 / 删除、微博发布 / 删除、新评论、备份完成七类事件自选推送到你的地址（可选签名校验），n8n / 飞书 / 自建系统一个地址全接走

    • 编辑器插件：API 1.1 + 远程安装（B8 插件半边）：插件开发者可用选区读写（拿到你选中的文字 / HTML、原地替换）、快捷键（如 Cmd+Shift+K）、onMount 初始化钩子；后台「插件 → 插件市场」新增远程安装——粘贴插件文件的 https 地址（或点市场条目「安装」），文件装进站内、随编辑器加载，卸载同样一键；插件市场条目从此可以带「安装」按钮而不只是外链

    • 广场 2.0 第一批：卡片墙 + 轻互动（B25 P0/P1/P2，官网 bloghao.com/plaza）：广场页从「一条河」升级成「一堵墙」——双视图（桌面默认双列卡片墙瀑布流、手机默认单列河流，偏好记住），卡片分三型（封面图卡 / 微博卡 / 文字卡），点站点名进站点视图（?site=N，「去逛逛 ↗」直达 TA 的博客号），侧栏换成近 7 日活跃榜 + 最新入驻（新站带「新」标，入驻 7 天内混排加权扶持）；匿名点赞（无账号，每 IP 每条每天一次，计数 ≥1 才显示）；广场带去的曝光 / 点击 / 点赞可在后台「插件 → 广场同步 → 数据」里看趋势；从广场点出去的链接带来源标记，站长在自己后台统计能看到广场回访量。隐私红线不变：无账号体系、互动全是匿名聚合计数、hub 不存任何访客身份；pull 补漏会自动用你 RSS 的站名补全名录显示

    • 文章「AI 生成」自愿申报：编辑器右侧「更多」新增「AI 生成」开关——本文由 AI 生成或 AI 深度参与创作时勾选，文章页 meta 行便显示 AI 生成标注（对齐《人工智能生成合成内容标识办法》的显式标识口径）；默认关、纯自愿，不勾选输出与历史版本字节级不变

    • 评论 IP 属地展示（可选，默认关）：后台「设置 → 互动」新增开关，开启后文章 / 留言板 / 微博评论区每条留言旁显示发布者的 IP 属地——国内到省（如「广东」）、海外到国家（如「美国」）、港澳台按地区。属地是写库瞬间定格的快照（与评论同一次请求），不做追溯回填；渲染端永远不做 IP 反查，无数据的旧评论与自托管形态（无 Cloudflare request.cf）恒不显示，宁缺毋假。开关只控制展示，采集与开关无关；评论表单上的披露提示随开关同生同灭

    • 首装新手引导卡：全新站点后台概览页出现一张引导卡——给站点起名 / 换头像 / 发一条微博 / 看一眼使用手册，四步完成状态实时计算（进度 N/4），做完或不想做都可一键跳过，从此不再出现；老站升级不带此键，永不显示

    • 内容可见范围（朋友圈式「N 天可见」）：后台「设置 → 站点」新增档位——全部可见（默认）/ 最近 3 天 / 1 个月 / 半年 / 1 年。选了窗口后，窗口外的文章与微博对游客和会员彻底不可见：列表不出现、直链 404、站内搜索搜不到、RSS / JSON Feed / sitemap 不包含、随机入口与「历史上的今天」隐藏、相关文章与上一篇下一篇同步收口，公开接口同样过滤——没有任何参数或入口能绕到窗口外。后台管理、备份、导出、AI 助手接入都不受影响，内容完整保留，随时改回「全部可见」即恢复

    • 后台列表时间范围筛选：后台「文章」「微博」管理列表新增范围条——全部 / 最近 3 天 / 1 个月 / 半年 / 1 年，找最近发的内容不用再无限翻页；与状态页签、关键词搜索、分页自由叠加。范围限制在服务端强制执行：页面只传档位名，具体的时间边界由服务端按白名单计算后进数据库查询，手改请求参数也拿不到档位之外的口径（乱传一律当「全部」）

    • 整站搬家：一键打包整站 + 一键还原到空站（B26）：后台「设置 → 数据导出 → 整站搬家」新增整站包——把整个站点（12 张业务表 + 图床全部图片）打包成一个 zip 下载，也能上传整站包，在另一个刚装好的站上一键还原（换服务器 / 换域名 / 重新部署，数据无损）。与 Markdown 包 / WXR（带走文章去别家系统）、备份（只导出不导入）分工不混。三条写死的契约：① 只还原到「没有内容的站」——永不覆盖、永不合并，刚装好的新站先删掉自带的示例文章与「关于我」页面（或直接用下面的「清空本站内容」）即可导入，否则明确报出挡路的内容；② 只装内容不装实例身份——不含管理员账号、会话与各类密钥，新站自己登录、自己填；③ 版本不匹配一律拒绝不猜——包比系统新会报错并列出差异，系统比包新则缺的列自动按默认值补。包落在图床的 bundles/ 目录（不公开，仅登录管理员可操作），单包 ≤2GB；只导入你自己站点的导出包（包里的页脚自定义 HTML 属站长自填内容，会原样带入，来源不明的包等于让陌生人往你站里写 HTML）。配套的清空本站内容：把任何站（刚装好的新站 / 装满内容的老站）一键变回「没有内容的站」，省掉手动逐条删进回收站——清空全部业务表与图床图片，保留站点设置、管理员账号、密钥与已上传的整站包；硬删不可撤销，需在弹窗里原样输入「清空本站」确认。用法见 GUIDE §19，API 契约见 API.md

    • 微博页也能按页码跳转（2026-10-17）：微博页（随手记）底部翻页条在「新一条 / 更早的」之外，新增页码输入框——填页码点「跳转」直接过去，不用一页页翻；与文章列表页的跳转框同款样式（七套主题共用，无新增样式）。按话题筛选时跳转会把话题一并带上，不会跳回全部列表

    • 读者侧「微信同款」交互件（2026-10-17）：文章页往下滚、顶部导航收起后，右上角浮出「…」聚合面板——分享 / 复制链接 / 正文字号（小 / 标准 / 大 / 特大四档，选一次就记住，只作用于正文，微博流不受影响）；面板配色跟随当前主题自动明暗适配，七套主题无需各自改造。图片查看器补齐微信手势：向下拖动直接关闭，长按弹出「保存图片 / 复制图片地址」

    • AI 抓取策略（B27）：后台「设置 → 站点状态」新增三档——默认放行 / 只许检索引用（seek） / 全部拒绝（deny）：把「训练型拒绝、检索引用型放行」写进 robots.txt（AI 爬虫名单内置 50+ 条，覆盖 GPTBot、ClaudeBot、字节爬虫等，独立 User-agent 组），并附 Content-signal 声明行；默认档输出与历史版本逐字节一致。后台「统计」页的 AI 抓取同步分栏「AI 训练抓取 / AI 检索引用」（两者商业含义相反；Claude 的训练与检索爬虫分开计数）。声明 ≠ 拦截，真拦截靠 Cloudflare AI Crawl Control 等托管平台

    • AI 可获取面（B28）：/llms.txt 站点导读索引（最新 100 篇条目 + 独立页面 + 订阅清单）、/llms-full.txt 全文合集（最新 50 篇，自动转成干净 Markdown）；每篇文章在地址后加 .md 可得 Markdown 版本，文章页 head 自动声明。防泄漏与 RSS 同一份口径：会员锁文只出摘要 + 引导、密码文整体退出（.md 404）、演示站 / 全站禁止收录 / AI 策略「全部拒绝」时整体关闭

    • 收录可见性守卫：后台概览页常驻收录状态提醒（开了「禁止搜索引擎收录」或闭站时橙色提示条 + 「去哪关」指路——整站对搜索引擎与 AI 关门却无人察觉的事故不再静默）；docker 自托管控制面的分站列表同样显示收录状态，开通脚本自带收录自检

    修复

    • 上传大文件一律失败（超 2MB 全部 413）：入站体积预检的上传豁免路径少了 /api 前缀（真实路径是 /api/admin/upload），于是上传端点一直按 2MB 的普通限额预检——视频、大图、开放接口配图只要超过 2MB 就地被拒，页面上只显示「上传失败」（前台图片因为上传前会压缩到几百 KB，所以一直没暴露）。现已修正，冒烟新增「上传体积预检链路」守着（3MB 必须放行 / 31MB 必须 413）
    • 视频偶尔被判「只支持 MP4 / WebM」：macOS 常把 .mp4 报成 video/quicktime，而客户端此前把「容器品牌无需改写」误当成「不认识的格式」直接拒掉。现在改为只认文件头：有 ftyp 就是 ISO-BMFF，品牌是 qt 的（iPhone 的 .mov）改写成 mp4，其余品牌原样按 mp4 上传；WebM 认 EBML 魔数，其它容器才提示换格式。另外，上传失败时会把服务端原话（如「请求体过大」「文件超过 25MB 限制」）显示出来，不再只有一句笼统的「上传失败」
    • 视频入口合并（站长拍板）：不再单设「视频」按钮，图片与视频共用同一个「加图」选择器，只保留「一条微博最多 1 个视频」的约束（多选时视频取第一个、其余当图片；拖拽 / 粘贴同样分流）
    • iPhone（iOS Safari）选不到图库里的视频：视频按钮的选择器以前只列 video/mp4 / video/webm，而 iOS 的「照片图库」是按它过滤的——iPhone 拍的视频是 .mov，于是图库里一个视频都不显示（2026-10-13 站长手机实测）。现在选择器写 video/*，选中后站点自动把 .mov 的容器改写成 MP4（只改文件头几字节的品牌位，不重编码、不损质量），H.264 的 iPhone 视频改完即全平台可放；HEVC（iPhone 默认的高效格式）上传时会提示一句「iPhone / Mac 正常，部分 Windows 浏览器放不出来」，想更稳可先导出 MP4。服务端「只收 MP4 / WebM」的白名单不变

    变更

    • SEO 收录口径收敛：标签聚合页与留言板 / 友链等薄内容页退出 sitemap 并 noindex（canonical 自指短链），sitemap 只提交有独立内容的页面；lastmod 取内容真实更新时间（首页 / 归档用最新文章、分类页用其下文章、微博流用最新微博），不再恒为「今天」
    • 缓存与性能批次：公开页面与订阅源 30 分钟边缘缓存（内容变更即时失效）；图床 /images/* 边缘缓存省跨境回源；文章 / 微博列表排序与评论计数补齐 D1 表达式索引（此前按行读取计费的热查询全表扫描，线上实测日读取量降一个数量级）；设置读取加共享快照层（热读免 D1 查询，写入推送式失效）
    • 自托管控制面增强（docker-poc）：分站详情页（前台 / 后台直达、租户数据统计、评论待审 / 会员 / 媒体量速览）、开通引导卡、分站自动进广场、分站收录状态列与开通自检、全部操作改「提交后重定向」（刷新不再弹重复提交确认）

    安全

    • 多轮增量安全复审修复，全部带回归测试。要点：
      • 改密码会话清理写反：管理员改密码后「保留当前会话」的比对拿 Cookie 明文直比库里哈希（恒不相等），实际把全部会话删光、把自己也踢下线——已修复并补真库用例
      • 后台防嵌套补强：X-Frame-Options 与 CSP frame-ancestors 双写（meta 兜底 + 静态响应头），旧浏览器也有防线
